# heart

一个用 HTML5 Canvas 绘制的跃动爱心页面。

## 效果

- 暗色背景 + 亮红色发光爱心
- 1000 个采样点按参数方程勾勒爱心轮廓
- 由 `Math.sin` 驱动的缩放，形成连续的心跳律动
- 自适应窗口 / 手机屏幕尺寸

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 入口页面，便于直接访问站点根地址 |
| `heart.html` | 原始文件名版本，你原文里的保存名 |

两个文件内容完全相同，保留两份只是为了兼容两种访问方式：

- `https://用户名.github.io/heart/` → 自动打开 `index.html`
- `https://用户名.github.io/heart/heart.html` → 也可直接访问

严格来说是重复内容。如果你只想保留一个，**留 `index.html`**（分享链接更短），
另一个可以在 GitHub 网页上直接删除。

## 说明

页面完全自包含，不依赖任何外部图片、字体或 CDN，
因此可以部署到任意静态托管平台直接运行。
